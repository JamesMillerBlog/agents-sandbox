# Issue tracker: Second Brain

Issues for this repository live as Obsidian notes in:

Vault: `Second Brain`; path: `00_Inbox/`

Use Obsidian tools to create, read, search, and update issue notes. Do not use
GitHub Issues as this repository's issue tracker.

## Issue notes

- Create new issues under `00_Inbox/`.
- Use a descriptive filename and include a `[[wikilink]]` in each note.
- Add one canonical triage value in YAML frontmatter:
  `labels: [needs-triage]`.
- Use `obsidian_search` to find related notes before creating duplicates.
- Use `obsidian_read` and `obsidian_append` for existing notes; preserve their
  substantive content.

Canonical labels are defined in `docs/agents/triage-labels.md`.
